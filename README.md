<h1 align="center">

**<u>Blog-Lite</u>**
</h1>


<p align="justify">
Blog-Lite is a blogging website that gives the user a place to write blogs and share with other fellow users. This document explains the organisation of this project and how to run the website.
</p>

## What's included

The project is structured as follows:

```bash
└──      Database/
│  └────      model.py
├──      README.md
├──      main.py
└──      instance/
├──      project_video.mp4
└──      report/
│  └────      report.pdf
└──      static/
│  └────      css/
│  │  └────      style.css
│  └────      images/
│  └────      uploads/
└──      templates/
│  ├────      dashboard.html
│  ├────      edit_post.html
│  ├────      login.html
│  ├────      pub_profile.html
│  ├────      pvt_profile.html
│  ├────      result.html
│  └────      signup.html 
```

## How To Run "Blog-Lite":

1. Go to the root folder and run the following command:

```
python main.py
```

### Running on localhost

2. Run the website on localhost server on 5000 port using

```
http://127.0.0.1:5000/
```

### Running on Replit


2. Run the website

```
https://BlogLite.akhilvashistha.repl.co
```
